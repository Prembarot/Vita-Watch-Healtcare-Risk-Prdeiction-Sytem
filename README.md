# 🩺 Vita Watch — Healthcare Risk Prediction System

Vita Watch is a **Machine Learning-based healthcare risk prediction system** that analyzes patient healthcare data and predicts potential health risks using a **Random Forest Classifier**.

## 🚀 Features

* Healthcare data analysis and preprocessing
* Random Forest-based risk prediction
* Interactive **Plotly Dash dashboard**
* Data visualization and analytics
* Saved ML model for prediction

## 🛠️ Tech Stack

**Python • Pandas • NumPy • Scikit-learn • Matplotlib • Plotly • Dash**

## 📂 Project Structure

```text
├── DashApp.py
├── VitaWatch.ipynb
├── healthcare_dataset_cp.csv
├── random_forest_model.pkl
├── Images/
└── WebsiteDash.bat
```

## ▶️ Run Locally

```bash
git clone https://github.com/Prembarot/Vita-Watch-Healtcare-Risk-Prdeiction-Sytem.git
cd Vita-Watch-Healtcare-Risk-Prdeiction-Sytem
```
